# References

`v0.7` &nbsp; `2026-11-17` &nbsp; `CC BY 4.0` &nbsp; <img src="../brand/img/tag-draft.svg" alt="Draft" height="20" align="absmiddle">

> **In short.** Standards, protocols and documents this specification builds on or refers to.

- EASA: Technical Specification for ADS-L transmissions using SRD-860 frequency band (ADS-L 4 SRD-860), Issue 2, 1 December 2025, ED Decision 2022/024/R.
- FLARM Technology: FLARM FAMP Public Protocol (FTD-116), version 1.02, 7 September 2026. FLARM is installed in more than 85,000 manned aircraft (flarm.com, 2026).
- RTCA DO-260B: Minimum Operational Performance Standards for 1090 MHz Extended Squitter ADS-B and TIS-B (Compact Position Reporting).
- Open Glider Network (OGN): OGN tracking protocol, open protocol description, glidernet.org.
- ISO 21815 series (Part 1:2022, Part 2:2021, Part 3:2023): Earth-moving machinery — Collision warning and avoidance.
- Hexagon Mining: Collision Avoidance System (formerly SAFEmine, based on FLARM technology), more than 65,000 units at more than 100 mine sites (2025).
- IEEE 1278.1: Standard for Distributed Interactive Simulation (DIS) — Application Protocols.
- IETF RFC 4082: Timed Efficient Stream Loss-Tolerant Authentication (TESLA), 2005.
- IETF RFC 5869: HMAC-based Extract-and-Expand Key Derivation Function (HKDF), 2010.
- NIST SP 800-56A Rev. 3: Recommendation for Pair-Wise Key-Establishment Schemes Using Discrete Logarithm Cryptography (ECDH), 2018.
- NIST SP 800-38A: Recommendation for Block Cipher Modes of Operation (CTR mode), 2001; FIPS 197: Advanced Encryption Standard (AES).
- ETSI EN 300 220-1: Short Range Devices (SRD) operating in the frequency range 25 MHz to 1 000 MHz, Part 1: Technical characteristics and methods of measurement.
- CEPT ERC Recommendation 70-03: Relating to the use of Short Range Devices (SRD), Annex 1.
- US Code of Federal Regulations, 47 CFR §15.247: Operation within the bands 902-928 MHz, 2400-2483.5 MHz and 5725-5850 MHz.
- Semtech: SX1261/2 Data Sheet (LoRa modem, packet format and time on air).
- N. Meratnia, R. A. de By: Spatiotemporal Compression Techniques for Moving Point Objects (TD-TR), EDBT 2004.
- RTCM Standard 10403: Differential GNSS Services, Version 3.
- NOAA NCEI and BGS: World Magnetic Model (WMM), current edition.
- World Sailing: The Racing Rules of Sailing 2025-2028.
- World Sailing Policy D12: Recognition Framework for Augmented Race Management Systems (ARMS), 27 February 2026.
